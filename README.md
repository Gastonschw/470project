# ResuRank AI

Resume-to-job ranking system for CSCE 470. Takes a resume and ranks ~30k job postings by relevance using three strategies: TF-IDF, Semantic (sentence-transformers), and a Hybrid blend of both.

## Setup

Requires Python 3.10+. Install dependencies:

```bash
cd resurank-ai
pip install -r requirements.txt
```

Download the [CareerBuilder Job Listing 2020 dataset](https://www.kaggle.com/datasets/promptcloud/careerbuilder-job-listing-2020/data) from Kaggle and place the LDJSON file in this directory.

## How to Run

### Rank jobs for a resume

```bash
python test_core.py --data marketing_sample_for_careerbuilder_usa-careerbuilder_job_listing__20200401_20200630__30k_data.ldjson --resume Malik_Rabb_Resume.docx
```

Use `--demo` instead of `--resume` to run with a built-in sample resume. Optional flags: `--sample N` (default 500), `--top-k N` (default 10), `--alpha F` (hybrid weight, default 0.5).

### Run evaluation

Computes P@k, R@k, and AP for all 3 rankers against 3 resumes using LLM-generated ground truth labels:

```bash
python run_evaluation.py
```

## Project Structure

| File | Description |
|------|-------------|
| `data_loader.py` | Loads and cleans the LDJSON job dataset |
| `resume_parser.py` | Extracts text from PDF/DOCX resumes |
| `ranker.py` | TFIDFRanker, SemanticRanker, HybridRanker |
| `skill_extractor.py` | Skill matching and gap analysis |
| `evaluation.py` | P@k, R@k, AP metrics and eval helpers |
| `run_evaluation.py` | Runs all rankers on all resumes and prints metrics |
| `test_core.py` | End-to-end demo: rank jobs for a single resume |
